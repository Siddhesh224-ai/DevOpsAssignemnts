# DynamoDB and RDS

## DynamoDB

DynamoDB is a managed NoSQL key-value/document database. Tables contain items made of attributes. Every item has a partition key; an optional sort key groups and orders related items. It fits high-scale, low-latency workloads such as sessions, carts, gaming state, and event metadata when access patterns are known.

## RDS

RDS manages relational engines including PostgreSQL, MySQL, MariaDB, Oracle, SQL Server, and Aurora. DB instances are protected with VPC networking, security groups, encryption, IAM-integrated controls, backups, and monitoring. Multi-AZ improves availability; read replicas scale reads and support some recovery/migration patterns. It fits transactional applications requiring SQL, joins, constraints, and mature relational tooling.
