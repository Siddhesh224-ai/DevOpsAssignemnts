# EC2 — Compute

EC2 provides resizable virtual machines. An AMI supplies the operating-system/root-volume template; instance families trade CPU, memory, storage, GPU, and price. Key pairs support SSH, security groups are stateful virtual firewalls, and EBS provides persistent block volumes.

Public IPs provide internet reachability when routing and policy allow it; private IPs are for VPC communication. Instances move through pending, running, stopping/stopped, shutting-down, and terminated states. Common uses include web/application servers, batch workers, build agents, legacy workloads, and custom compute needing OS-level control.
