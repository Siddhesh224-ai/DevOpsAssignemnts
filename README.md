# DevOps Homework

Homework for Sessions 9–21 is stored inside each corresponding session directory:

```text
session*/homework/
├── README.md      # completed tasks, notes, and reproduction commands
├── evidence.txt   # real command output
└── evidence.png   # rendered output screenshot
```

Examples: `session9-k8s/homework/`, `session-15-helm/homework/`, and `session21-python/homework/`.

Session 21 contains the TaskBoard application assignment only; the separate capstone/final project was intentionally not added.
